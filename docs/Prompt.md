คุณคือผู้เชี่ยวชาญการออกแบบระบบ IT 
สิ่งที่ให้ท่านทำคือสร้าง Software specification เพื่อใช้สร้างระบบชื่อ "DailyNews" และนำเอกสารดังกล่าวไปเก็บยัง https://github.com/Ittipolint/dailynews
รายละเอียด feature/function ของระบบ DailyNews
   - Feature การรับข่าวเข้าสู่ระบบ (ฺBackground Job)
     - รวบรวมข่าวจากแหล่งข่าวที่สำคัญรอบโลก เบื้องต้นขอให้ดึงแหล่งข่าวที่สำคัญรอบโลกเข้ามาใส่ในระบบให้ก่อน
     - มีหน้าจอที่สามารถกำหนดแหล่งข่าวเพิ่มเติม แก้ไข ลบทิ้ง Set active/in-active ได้ 
     - เก็บ data ข่าว ลงในฐานข้อมูล
     - แปลข่าวจากภาษาต้นทางมาเก็บเป็น 3 ภาษาหลัก ได้แก่ ภาษาไทย ภาษาอังกฤษ ภาษาจีน
     - มีหน้าจอ chat สำหรับให้ค้นหาข่าวย้อนหลังเป็นระบบ AI Graph RAG
     - ถ้ามี idea อื่นๆที่ดีก็เพิ่มเข้ามาได้
   - Feature การส่งข่าว (Background Job)
     - ส่งข่าวไปยังสมาชิกตามช่องทาง และเวลาที่กำหนด
     - สมาชิกรับข่าว แต่ละสมาชิกสามารถรับข่าวได้มากกว่า 1 ช่องทาง โดยกำหนด
     - ช่องทางที่กำหนดให้มีเริ่มต้นได้แก่ LINE ส่วนตัว, LINE OA, Email
     - ถ้ามี idea อื่นๆที่ดีก็เพิ่มเข้ามาได้
   - Feature การบริหารจัดการแหล่งข่าว
     - การเพิ่ม แก้ไข ลบ active/not active แหล่งข่าว
   - Feature การบริหารจัดการสมาชิก
     - จัดการประเภทสมาชิก เช่น สมาชิกองค์กร สมาชิกบุคคล เป็นต้น 
     - สมาชิกสามารถเข้ามา setup ประข่าวที่สนใจจะรับได้
     - สมาชิกสามารถ setup schedule ที่จะให้ส่งข่าวในแต่ละประเภทได้ตามวัน เวลาที่กำหนด
     - การเก็บค่าสมาชิก ต่ออายุสมาชิก ยังไม่มีใน phase นี้ **** แต่ให้วางโครงสร้างเพื่อรองรับใน phase ถัดไป
   - Feature Dashboard สำหรับ Admin และสมาชิก
     - ขอให้เสนอ Idea ของท่านลงใน Software Specification
     - แต่อย่างน้อยต้องมีจำนวนข่าวที่ดึงมาจากแต่ละ source ในแต่ละวัน แต่ละสัปดาห์ แต่ละเดือน
     - จำนวนข่าวที่ส่งออกไปในแต่ละวัน แต่ละสัปดาห์ แต่ละเดือน
   - Feature Reference Data เพื่อ setup ค่าการทำงานต่างๆของระบบ
     - การเพิ่ม แก้ไข ลบ active/not active สมาชิกที่จะรับข่าว และ Credential ต่างๆที่จำเป็นในการส่งข่าวออกไปให้สมาชิกแต่ละคน
     - ส่วนของ Admin การแก้ไข Credential ของระบบที่สำคัญต่างๆ
     - ถ้ามี idea อื่นๆที่ดีก็เพิ่มเข้ามาได้
เทคโนโลยีที่ใช้
   - OS ของ Server คือ Ubuntu และ Software ทั้งหมดจะเป็น Opensource
   - n8n ทำหน้าที่เป็นกลไก workflow ที่ดึงข่าวจากแหล่งข่าวเป้าหมายมาบันทึกลงฐานข้อมูลข่าว
   - n8n ทำหน้าที่ส่งข่าวล่าสุดให้กับผู้เป็นสมาชิกของระบบตามช่องทางที่สมาชิกแต่ละท่านกำหนด
   - ฐานข้อมูลเก็บข่าว และข้อมูลอื่นๆทั้งหมดให้ใช้ Postgres
   - Dashboard ให้ท่านเลือกใช้ Opensource ที่นิยมใช้กันอย่างแพร่หลาย
   - LLM และ Vector Database ที่ใช้สำหรับระบบ RAG ขอให้เลือกตัวที่เพียงพอกับ Hardware ที่มี
   - ภาษาหลักที่ใช้ในการสร้าง Web ใช้ NextJS และ backend ใช้ NodeJS โดยเลือก Framework ที่นิยมใช้กันแพร่หลายและเป็นมาตราฐาน
   - Technology tools ต่างๆที่ใช้นอกเหนือจากนี้ให้กำหนดลงมาใน Software Specification ให้ครบ
